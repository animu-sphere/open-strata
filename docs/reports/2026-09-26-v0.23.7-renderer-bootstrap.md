# v0.23.7 renderer bootstrap verification

## Scope and environment

Pre-release verification of the v0.23.7 changes on `codex/v0.23.7`, using the
locally built `ost 0.23.7` and renderer template 0.5.2. A fresh `release-smoke`
project was generated under the OpenStrata working tree; the downstream
hydra-toon checkout was not modified.

Environment: Windows, MSVC, NVIDIA RTX A5000 (Vulkan device API 1.3.280),
Vulkan SDK headers/loader from 1.3.290 and `slangc` from 1.4.350. The `core`
profile and the existing `lookdev` OpenUSD 26.08 runtime were used. The latter
resolved the workstation's `C:/usd/openusd-26.08-usdview` installation.

The source finding is
[hydra-toon report 01](https://github.com/animu-sphere/hydra-toon/blob/main/docs/reports/ost/01-2026-09-26-v0.23.6-renderer-template-bootstrap.md).

## Procedure and results

| Procedure | Observed result |
| --- | --- |
| Generate renderer, build core, run `ost test` | Headless GPU evidence produced; 3 of 3 CTest cases passed. |
| Run an unchanged build, then `ost validate` | Passed; primary report retained its original producer binding. |
| `ost renderer viewport -- --frames 8 --hidden` | Eight frames presented on RTX A5000; zero swapchain recreations. |
| Run ordinary `ost validate` after viewport | Passed; separate viewport build did not invalidate the default build. |
| `ost validate --intent renderer-viewport` | Passed with built-in intent selection and durable launch validation. |
| Declare Hydra intent with `RELEASESMOKE_ENABLE_HYDRA2=ON`; build with `--profile lookdev --intent hydra` | OpenUSD 26.08 adapter compiled successfully; no C4819 warning in the core or Hydra build log. |
| Run `ost test` and `ost validate` with the same Hydra selectors | 7 of 7 CTest cases passed, including `testusdview`; validation passed. |

The native renderer lifecycle regression group also passed all seven cases
with `OST_RUN_NATIVE_LIFECYCLE=1`. It covers repeated unchanged builds,
validation after tests, rejection of a modified report and an incompatible
previous build configuration, and failed/timed-out producer handling.

The full Rust workspace tests, Clippy with warnings denied, formatting,
documentation checks and dependency license/advisory checks passed. Generated
CLI documentation and third-party attribution were refreshed.

## Limits

This is local candidate verification, not a hydra-toon rerun with the published
release. It proves the generated bootstrap on this workstation, not avatar
rendering, the pre-98 Hydra API branch, or the hosted OS/OpenUSD renderer matrix.
The release CI separately checks portable Rust and SDK fixtures; those fixtures
do not constitute real renderer GPU acceptance on every platform.
