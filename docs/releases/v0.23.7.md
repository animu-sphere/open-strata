# v0.23.7 - Renderer bootstrap and durable validation

## Objective

Resolve the five requests in
[hydra-toon report 01](https://github.com/animu-sphere/hydra-toon/blob/main/docs/reports/ost/01-2026-09-26-v0.23.6-renderer-template-bootstrap.md):
an unchanged build must preserve valid renderer evidence, and a viewport launch
must not make the default build fail validation.

## Shipped fixes

- Successful builds retain previous renderer bindings only when the previous
  completion validates against the same build identity and the report remains
  untouched with its recorded SHA-256. The report keeps its original producer;
  changed, missing, untracked or incompatible evidence is not adopted.
- Durable viewport launch records are scoped to the build directory. Legacy
  target-wide records from another build are skipped; matching records still
  enforce identity, digest and exit-state checks.
- `ost validate --intent renderer-viewport` selects the built-in viewport
  build without a project declaration. Explicit project intents take precedence.
- Renderer template 0.5.2 supports the `HD_API_VERSION >= 98` container-schema
  GPU flag in OpenUSD 26.08, retaining the older field-based branch. An absent
  GPU flag means enabled.
- The template sets MSVC `/utf-8` and declares one frame context, matching the
  generated backend's one-frame-in-flight behavior.
- Reference-project documentation adds hydra-toon and USD Physics Plugins and
  refreshes USD Raster Plugins for its v0.2.0 release and current mesh slice.

## Compatibility and limits

Workspace crates and CLI are version `0.23.7`; manifest and artifact formats
are unchanged. Existing scaffold sources are not rewritten on upgrade: apply
the template fixes to an existing renderer explicitly. A binding already lost
under an older CLI needs a report-producing rebuild before it can be retained.

The renderer remains a bootstrap skeleton. Hosted OS/OpenUSD acceptance and a
hydra-toon rerun with the published CLI remain in the
[current roadmap](../roadmap/current.md); this release does not claim new avatar
rendering capabilities or downstream hardware acceptance.

Local fresh-template verification is recorded in the
[renderer bootstrap report](../reports/2026-09-26-v0.23.7-renderer-bootstrap.md),
including RTX A5000 presentation and seven passing OpenUSD 26.08 Hydra tests.
