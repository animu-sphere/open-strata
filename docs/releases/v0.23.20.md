# v0.23.20 — Target-specific bundle stages in plugin viewer sessions

`ost plugin view` and `ost plugin test-view` now register the primary bundle
and its companions from the selected target's managed bundle stages. This
lets bundles that install their `plugInfo.json` and libraries outside the
source tree open fixtures in usdview. [Issue #296](https://github.com/animu-sphere/open-strata/issues/296)

On Windows, `test-view` opened the reported `ABeautifulGame.glb` using the
staged glTF plugin and an OpenUSD 26.08 lookdev runtime.

## Compatibility

Bundles without a managed stage for the selected target still use their
source-tree outputs. Relative fixtures and test reports still resolve under
the primary bundle's source root. Both viewer commands require a runtime with
usdview.
