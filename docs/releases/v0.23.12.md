# v0.23.12 — macOS lookdev Metal producer

Adds the macOS arm64 producer cell for the CY2026 OpenUSD 26.08 lookdev runtime.

## Changes

- The canonical lookdev plan now includes `26.08-metal-macos-arm64` alongside
  the existing Linux and Windows GL leaves, under
  `oci://ghcr.io/animu-sphere/openstrata-runtime-cy2026-lookdev`.
- The macOS publisher selects Metal by default for `-Profile lookdev`; the
  existing macOS SDK 15.5 and deployment target 13.0 requirements apply.
- Planner tests cover the leaf's tag, viewer build requirement, SDK floor and
  deployment target. The publishing guide documents the host-specific plan
  and the build, validation, export and digest-pull workflow.

## Compatibility and verification

Linux and Windows lookdev GL leaves and the `usd` profile matrix are unchanged.
The macOS lookdev leaf requires an Apple Silicon host with a physical Metal
device, OpenUSD 26.08, Python 3.13 and the viewer Python packages. A planned
leaf is not a published artifact: run the producer's runtime, graphics,
artifact and distribution gates before consuming its registry digest.
