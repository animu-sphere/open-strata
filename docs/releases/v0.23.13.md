# v0.23.13 — Formation Python launch and short materialization paths

Repairs the two blocking Formation issues in hydra-toon OST report 05:
[Python entry-point launch](https://github.com/animu-sphere/open-strata/issues/259)
and [deep Windows materialization paths](https://github.com/animu-sphere/open-strata/issues/260).

## Changes

- `formation env`, `doctor` and `run` discover the runtime's interpreter using
  the same Python selection as runtime validation. The selected interpreter's
  directory joins the composed `PATH`; arbitrary parent search paths are not
  inherited. Host Python must match the runtime's required major/minor ABI.
- `doctor` and `run` share executable resolution. Extensionless Python tools
  such as `usdview` and `testusdview`, `.py` files and standard OpenUSD Python
  shims run through the selected interpreter. Missing Python fails the command
  check and launch with an actionable diagnostic. Native commands do not
  require Python.
- Materialization uses `$OST_HOME/artifacts/f/<16-character-id>/`, independent
  of the manifest directory and Formation name. Each invocation verifies and
  extracts into a fresh tree; retained `env` trees are never reused as trusted
  caches. Transient trees are removed after use.
- Run evidence includes the resolved executable, script and selected Python.
  Portable locks continue to exclude machine-local interpreter and extraction
  paths.

## Compatibility and limitations

Existing Formation manifests and locks remain valid. Platform Python remains a
host prerequisite; this release does not bundle or install it. The selected
Python must be available on each consumer host. Use a short `OST_HOME` on Windows
if the store itself is deeply nested; legacy loaders can still reject long
artifact-internal paths.

Regression fixtures cover Python scripts and shims, missing/wrong-ABI host
Python, non-executable commands, deep project directories, retained-tree
isolation and portable locks. Real rendering evidence is recorded in the
[verification report](../reports/2026-09-27-v0.23.13-formation-launch.md).
