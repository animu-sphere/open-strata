# v0.22.2 - Static musl graphics probe handling

## Objective

v0.22.2 is a focused patch release for static musl OpenStrata binaries. It
keeps runtime validation honest when the statically linked CLI cannot dynamically
load host graphics libraries.

## Completed capabilities

- **Static musl graphics-loader handling.** Detect static musl builds and skip
  host graphics-loader probes instead of attempting an unsupported dynamic load.
- **Explicit validation reporting.** Record the graphics-loader check as skipped
  with a clear explanation of the packaging limitation.
- **Portable runtime validation.** Preserve graphics-loader probing for targets
  that can dynamically load host graphics libraries.

## Compatibility notes

- This is a patch release on the v0.22.1 artifact and runtime compatibility
  contracts. The approved OpenUSD, platform, toolchain, provider, graphics,
  artifact, and evidence requirements are unchanged.
- Static musl binaries continue to validate the checks available to their
  packaging environment; host graphics-loader probing is explicitly skipped.

## Known limitations

- The normalized release matrix remains deliberately constrained to its
  v0.22.0 compatibility cells; broader operating-system and OpenUSD matrices
  remain planned work for later milestones.
- DCC host adapters and the pinned host support matrix remain deferred to
  v0.23.0.
