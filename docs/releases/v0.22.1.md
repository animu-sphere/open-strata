# v0.22.1 - OpenUSD dependency capture maintenance

## Objective

v0.22.1 is a focused patch release for the managed OpenUSD source-build path.
It makes dependency capture resilient to the line endings and marker wording
used by current OpenUSD 26.08 `build_usd.py` sources, while refreshing pinned
dependencies and release-pipeline actions.

## Completed capabilities

- **Resilient `build_usd.py` dependency capture.** Normalize CRLF source files
  before matching the dependency-install hook and accept the current marker
  wording used by OpenUSD 26.08, including its trailing newline.
- **Pinned dependency refresh.** Update the workspace pins for `thiserror`,
  `clap`, and `ureq`, together with the corresponding locked dependency graph.
- **Release-pipeline maintenance.** Refresh the pinned GitHub Action revisions
  used by the license and release workflows without changing their contracts.
- **Regression coverage.** Exercise marker counting with both normalized LF and
  CRLF input so line-ending changes do not silently disable dependency capture.

## Compatibility notes

- This is a patch release on the v0.22.0 artifact and runtime compatibility
  contracts. The approved OpenUSD, platform, toolchain, provider, graphics,
  artifact, and evidence requirements are unchanged.
- The managed source-build path now recognizes the OpenUSD 26.08 dependency
  marker variants covered by the runtime command's capture logic.

## Known limitations

- The normalized release matrix remains deliberately constrained to its
  v0.22.0 compatibility cells; broader operating-system and OpenUSD matrices
  remain planned work for later milestones.
- DCC host adapters and the pinned host support matrix remain deferred to
  v0.23.0.
